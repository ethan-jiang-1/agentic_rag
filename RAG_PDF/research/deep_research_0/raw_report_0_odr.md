Structure-Aware PDF Parsing (Layout & Content Extraction)
Document Parsing Unveiled: Techniques, Challenges, and Prospects for Structured Information Extraction – Qintong Zhang et al. – arXiv (October 2024). This is a comprehensive survey of document parsing methods, from modular layout analysis pipelines to end-to-end vision-language models, covering text layout detection, table/figure extraction, OCR, and challenges in handling complex PDF layouts. Publication: arXiv preprint. URL: https://arxiv.org/abs/2410.21169
OmniDocBench: Benchmarking Diverse PDF Document Parsing with Comprehensive Annotations – Zhiyu Chen et al. – arXiv (December 2024). Introduces a large-scale benchmark dataset covering 9 types of PDFs with rich layout annotations (titles, paragraphs, tables, figures, formulas, etc.) and text content, enabling evaluation of both pipeline-based and end-to-end PDF parsing methods. The paper compares existing models and highlights strengths/weaknesses on different document types. Publication: arXiv preprint. URL: https://arxiv.org/abs/2412.07626
PDF-to-Tree: Parsing PDF Text Blocks into a Tree – Yue Zhang et al. – Findings of EMNLP 2024 (November 2024). Proposes a new task of organizing PDF text blocks into a hierarchical tree (sections, subsections, paragraphs, footnotes, table cells, etc.) rather than a single reading order. A transition-based parsing algorithm with multimodal (text+layout) features is introduced, achieving ~94% accuracy in reconstructing document structure – useful for downstream tasks like RAG that require section-aware indexing. Publication: EMNLP 2024 Findings. URL: https://aclanthology.org/2024.findings-emnlp.628.pdf
DocLayout-YOLO: Enhancing Document Layout Analysis through Diverse Synthetic Data and Global-to-Local Adaptive Perception – Zhiyuan Zhao et al. – arXiv (October 2024). Presents a high-speed yet accurate layout analysis model for PDFs that combines visual and textual cues. It introduces a synthetic document dataset (DocSynth-300K) for pretraining and a YOLO-based model with a novel global-to-local receptive field module. The result is a layout detector that matches the speed of vision-only models while improving accuracy on detecting titles, text blocks, tables, images, etc. Publication: arXiv preprint (Shanghai AI Lab). URL: https://arxiv.org/abs/2410.12628
A Comparative Study of PDF Parsing Tools Across Diverse Document Categories – Narayan S. Adhikari & Shradha Agarwal – arXiv (October 2024). An evaluation study comparing 10 popular PDF parsing libraries and AI models (e.g. PyMuPDF, pdfplumber, pdfminer, Tabula, Camelot, as well as ML models like Google’s Nougat and Microsoft’s TableTransformer) on the DocLayNet dataset. It benchmarks text extraction and table recognition across 6 document types (scientific, patents, financial, etc.), highlighting that no single parser excels on all types and pointing out gaps for complex layouts. Publication: arXiv preprint. URL: https://arxiv.org/abs/2410.09871
Structure-Enhanced RAG Systems (Retrieval Augmentation with Document Structure)
Developing Retrieval Augmented Generation (RAG) based LLM Systems from PDFs: An Experience Report – Ayman A. Khan et al. – arXiv (October 2024). Describes practical lessons from building RAG pipelines using PDFs as the knowledge source. It covers end-to-end steps including PDF preprocessing (OCR and parsing), chunking strategies, indexing, and generation. The report discusses challenges like preserving domain context and handling PDF-specific issues, and compares using OpenAI GPT APIs vs. open-source Llama models for the RAG implementation. Publication: arXiv preprint. URL: https://arxiv.org/abs/2410.15944
ChunkRAG: Novel LLM-Chunk Filtering Method for RAG Systems – Ishneet S. Singh et al. – arXiv (Nov 2024). Proposes a retrieval-augmented generation framework that improves fidelity by semantically chunking documents and then using an LLM-based relevance scorer to filter out irrelevant chunks before generation. By only feeding highly relevant, non-redundant chunks to the LLM, ChunkRAG reduces hallucinations and boosts factual accuracy in the generated answers. Publication: arXiv preprint. URL: https://arxiv.org/abs/2410.19572
HtmlRAG: HTML is Better Than Plain Text for Modeling Retrieved Knowledge in RAG Systems – Jiejun Tan et al. – The Web Conf 2025 (WWW) (to appear, preprint Nov 2024). Investigates using the original HTML structure of web documents in retrieval-augmented generation instead of stripping to plain text. The authors note that valuable structural cues (HTML tags for headings, lists, tables) are lost in plain text, and show that keeping a cleaned, pruned HTML format leads to more coherent and accurate answers. They introduce HTML cleaning/pruning techniques to fit the context window and demonstrate improved QA performance over plain-text RAG. Publication: The Web Conference 2025 (ACM WWW) – accepted paper. URL: https://arxiv.org/abs/2411.02959
PathRAG: Pruning Graph-based Retrieval Augmented Generation with Relational Paths – Boyu Chen et al. – arXiv (February 2025). Focuses on graph-structured retrieval for RAG. Instead of a flat collection of text chunks, it organizes a document corpus as a graph of interconnected passages (capturing relationships like hyperlinks or section links). PathRAG then retrieves the most relevant paths in this graph and converts them into a concise textual prompt for the LLM. This path-based approach prunes redundant context and guides the LLM through a logical chain of retrieved evidence, yielding more accurate multi-hop answers than standard chunk RAG. Publication: arXiv preprint. URL: https://arxiv.org/abs/2502.14902
RAS: Retrieval-And-Structuring for Knowledge-Intensive LLM Generation – Pengcheng Jiang et al. – arXiv (February 2025). Proposes a framework that combines retrieval with on-the-fly structuring of knowledge for complex queries. RAS performs iterative retrieval and dynamically builds a query-specific knowledge graph from retrieved text, then uses a graph-augmented LLM to reason over this structured information. In essence, it introduces structured knowledge integration into RAG: theme-scoped retrieval to narrow focus, an action planner that issues sub-queries, and conversion of text snippets into a graph of entities/relations that the LLM uses to generate the final answer. This approach (aimed at knowledge-intensive tasks) outperforms standard RAG baselines on several datasets. Publication: arXiv preprint (under review, ICML 2025). URL: https://arxiv.org/abs/2502.10996
Multimodal & Visual-Semantic Document Understanding Models
DocLLM: A Layout-Aware Generative Language Model for Multimodal Document Understanding – Dongsheng Wang et al. – ACL 2024 (August 2024). Introduces a lightweight extension of LLaMA 2 (7B) that can handle visually rich documents by incorporating spatial layout features. DocLLM uses only text and 2D bounding-box coordinates (no heavy image encoder) to represent layout; it modifies the transformer attention to fuse text and layout positions. Through pre-training on unlabeled documents and fine-tuning on instruction data (for tasks like form QA, invoice understanding, etc.), DocLLM significantly outperforms other 7B-sized models on document QA and information extraction tasks, showing the benefit of layout-aware reasoning. Publication: Proceedings of ACL 2024. URL: https://aclanthology.org/2024.acl-long.463/
LayoutLLM: Layout Instruction Tuning with Large Language Models for Document Understanding – Chuwei Luo et al. – CVPR 2024 (June 2024). Proposes an approach to better utilize document layout information in large language models. LayoutLLM introduces a layout-aware instruction tuning framework: it pre-trains the model on synthesized tasks that incorporate spatial structure (document-level, region-level, and segment-level tasks) and uses a “Layout Chain-of-Thought (LayoutCoT)” module to guide the model’s focus to relevant regions when answering questions. This method yields improved accuracy on DocVQA and document reasoning benchmarks compared to vanilla LLMs, demonstrating that injecting layout understanding (e.g., reading order, hierarchy) into LLMs enhances document QA performance. Publication: CVPR 2024 (IEEE). URL: https://arxiv.org/abs/2404.05225
DocLayLLM: An Efficient Multi-Modal Extension of Large Language Models for Text-Rich Document Understanding – Wenhui Liao et al. – arXiv (August 2024). Presents a multimodal LLM that integrates vision (document images) and text without a dedicated vision encoder. DocLayLLM converts document image patches and their 2D positions into “tokens” that are fed directly into the LLM along with text, allowing the model to natively perceive layout and visual elements. It also employs a novel training strategy using chain-of-thought (CoT) data generation and “CoT annealing” to gradually improve reasoning. This design achieves strong accuracy on document understanding tasks while being computationally efficient (trained with ~3M examples and LoRA fine-tuning). Publication: arXiv preprint. URL: https://arxiv.org/abs/2408.15045
LayTokenLLM: A Simple yet Effective Layout Token in LLMs for Document Understanding – Zhaoqing Zhu et al. – arXiv (March 2025). Proposes a lightweight method to inject layout information into a language model by using a special layout tokenization scheme. Instead of adding separate position embeddings or image features for layout (which can reduce the available sequence length for text), LayTokenLLM represents spatial layout as special tokens interleaved with text in a way that reuses existing position indices. This approach preserves full text context length while still encoding layout, leading to performance gains on tasks like document QA and information extraction without architectural changes. Publication: arXiv preprint. URL: https://arxiv.org/abs/2503.18434
PP-DocBee: Improving Multimodal Document Understanding Through a Bag of Tricks – Feng Ni et al. – arXiv (March 2025). An industrial research (Baidu PaddlePaddle team) effort that boosts document-focused multimodal LLMs by data-centric methods. PP-DocBee introduces a large synthetic document dataset (mixing text, tables, and charts) including a new 477k sample Chinese document corpus, and applies several training tricks (like multimodal instruct tuning and prompt templates sensitive to document type). Applied to an open-source vision-text model (Qwen-VL), these techniques yield state-of-the-art results on document QA benchmarks, all while maintaining a relatively lightweight model design. Publication: arXiv preprint. URL: https://arxiv.org/abs/2503.04065
